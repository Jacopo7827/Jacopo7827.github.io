Panoramica

Autolavaggio self-service: il giocatore parcheggia sul punto di lavaggio, usa l'idropulitrice fissa per iniziare, paga e lava il veicolo a mano con una lancia a pressione. Ogni zona dell'auto (anteriore, posteriore, lati, tetto) va lavata; lo sporco del veicolo scende davvero mentre spruzzi.

  • Fasi: schiuma, risciacquo, cera protettiva (il veicolo resta pulito per un tempo configurabile)
  • Idropulitrice fissa per ogni postazione, posizione e rotazione da config (vec4)
  • Tubo fisico tra idropulitrice e lancia, getto e schizzi visibili anche agli altri giocatori
  • Menu con programmi, saldo e metodo di pagamento; HUD con avanzamento per zona
  • Compatibile con ESX, QBCore, Qbox e standalone; ox_target opzionale
  • Anti-exploit lato server (distanze, postazioni occupate, tempi minimi) e log Discord

Installazione

  1. Scarica la risorsa dal portale Cfx: portal.cfx.re → Assets → Granted Assets, con lo stesso account Cfx con cui l'hai acquistata.
  2. Estrai la cartella autolavaggio dentro resources/ del server.
  3. Nel server.cfg aggiungi ensure autolavaggio dopo il framework (es. es_extended) e dopo ox_target se lo usi.
  4. Imposta le coordinate delle tue postazioni in config.lua (vedi Stazioni).
  5. Riavvia il server. In console vedrai [Autolavaggio] v1.0.0 by MintDev e il link del Discord di supporto.
Requisiti: OneSync attivo e artifact FXServer aggiornato. La license key del server (sv_licenseKey) deve appartenere allo stesso account Cfx che ha acquistato la risorsa. Il framework e ox_target vengono rilevati da soli (Config.Framework = 'auto', Config.Target = 'auto').

Come si usa in gioco

  1. Parcheggia il veicolo sul marker della postazione (rosso = postazione occupata) e scendi.
  2. Vai all'idropulitrice e premi ALT (ox_target) → Inizia lavaggio. Senza ox_target: E vicino all'idropulitrice.
  3. Scegli il programma e il metodo di pagamento (contanti o banca) e premi Paga e inizia.
  4. Dalla stessa idropulitrice: ALT → Prendi la lancia (oppure E).
  5. Spruzza con il tasto sinistro del mouse su tutte le zone indicate dall'HUD. Completata una fase si passa alla successiva.
  6. A fine lavaggio parte un'inquadratura attorno all'auto pulita (E per saltarla).
TastoAzione
EInizia lavaggio / prendi la lancia (modificabile dal giocatore in Impostazioni → Tasti → FiveM)
Tasto sinistroSpruzza (si mira con la camera)
RCambia ugello: getto concentrato ↔ ventaglio
XRiponi la lancia
X (tenuto)Annulla il lavaggio (senza lancia in mano)

Stazioni, idropulitrici e blip

Le postazioni si configurano in Config.Stations. Ogni stazione può avere più postazioni (bays).

Config.Stations = {
    {
        label = 'Strawberry',
        blip  = true,                     -- false = nessun blip in mappa per QUESTA stazione
        -- blipLabel = 'Lavaggio Centro', -- (opzionale) nome del blip
        bays = {
            {
                vehicle = vec4(26.59, -1392.03, 29.36, 0.0),   -- dove si ferma il veicolo
                machine = vec4(30.09, -1392.03, 29.36, 90.0),  -- idropulitrice fissa
                -- radius = 3.0,                               -- (opzionale)
            },
        },
    },
}
CampoDescrizione
labelNome della stazione (usato nei log).
bliptrue mostra il blip di questa stazione, false lo nasconde. Aspetto comune in Config.Blip.
blipLabelTesto del blip; se assente usa quello della lingua (“Autolavaggio”).
vehiclevec4(x, y, z, heading): punto in cui si deve fermare il veicolo. Il marker viene disegnato qui, orientato come l'heading.
machinevec4(x, y, z, heading): idropulitrice fissa. Il 4° valore è la rotazione in gradi. Se la togli, l'idropulitrice compare accanto al veicolo solo durante il lavaggio.
radiusTolleranza in metri del punto di sosta (default Config.BayRadius).

Prendere le coordinate

  1. In config.lua metti Config.Debug = true e riavvia la risorsa.
  2. Parcheggia dove deve fermarsi il veicolo e, dentro l'auto, scrivi /carwashpos → ottieni vehicle = vec4(...).
  3. Scendi, mettiti dove vuoi l'idropulitrice, guarda nella direzione in cui vuoi girarla e scrivi /carwashpos → ottieni machine = vec4(...).
  4. Copia le righe (compaiono in notifica e in console F8) nel config, poi rimetti Config.Debug = false.
Le coordinate machine di esempio incluse sono indicative: sistemale con /carwashpos sulla tua mappa.

Blip

Config.Blip = { enabled = true, sprite = 100, color = 3, scale = 0.8 }

enabled = false spegne tutti i blip; per spegnerne solo alcuni usa blip = false nella singola stazione.

Lancia e idropulitrice

La lancia mint_pressure_lance è inclusa in stream/ e viene caricata dal fxmanifest.lua. Se il modello non fosse disponibile, lo script usa automaticamente la lancia di riserva successiva in Config.Gear.lances.

OpzioneDescrizione
networkedGli altri giocatori vedono la lancia (true consigliato).
machineModelsModelli dell'idropulitrice, provati in ordine.
lancesLance in ordine di preferenza: model, bone, offset, rot, tip (punta dell'ugello), hose (aggancio del tubo).
fxOffset / fxRotationPunto e correzione della direzione del getto per le lance senza tip.
holdAnim / pickupAnimAnimazioni per tenere e prendere la lancia.
hoseTubo: enabled, length (m), snapExtra, ropeType, machineOffset.
Per regolare la posizione della lancia in mano: Config.Debug = true, prendi la lancia e usa /carwashprop x y z rotX rotY rotZ; i valori finali vanno copiati nella lancia giusta di Config.Gear.lances.

Notifiche

NotifyConfig = {
    System   = 'esx',          -- 'esx' | 'nui' | 'custom'
    Title    = 'Autolavaggio',
    Duration = 5000,
    Position = nil,            -- es. 'top-right' (nil = quella di esx_notify)
    Types = { success = 'success', error = 'error', warning = 'warning', info = 'info' },
}

function NotifyConfig.Custom(message, notifyType, duration)
    -- esempio: exports['okokNotify']:Alert(NotifyConfig.Title, message, duration, notifyType)
end

Con 'esx' usa le notifiche base di ESX (esx_notify); se non è avviato, lo script usa da solo le sue notifiche grafiche ('nui').

Server, log e pagamenti

File server/sv_config.lua (non viene inviato ai client):

ServerConfig.Webhook = ''   -- URL webhook Discord per i log (vuoto = spento)

-- Solo modalità standalone: collega qui il tuo sistema di soldi
ServerConfig.StandaloneCharge = function(source, account, amount)
    return true
end
ServerConfig.StandaloneBalance = function(source)
    return nil
end

Il server controlla distanza del giocatore e del veicolo, postazioni occupate, saldo e tempo minimo di lavaggio; i lavaggi troppo veloci vengono segnalati nei log.

Testi e lingue

Tutti i testi sono in locales/it.lua e locales/en.lua. Per cambiare una frase modifica il valore della chiave corrispondente; per aggiungere una lingua copia un file, cambia Locales['it'] nel nuovo codice e impostalo in Config.Locale.

Comandi

ComandoDescrizione
/carwashpos(Debug) In auto: vehicle = vec4(...). A piedi: machine = vec4(...).
/carwashprop x y z rx ry rz(Debug) Sposta la lancia in mano.
/carwashfx x y z rx ry rz(Debug) Corregge la direzione del getto.
carwashcheck(F8) Controlla se il prop della lancia è registrato e caricato.

Prestazioni

  • Lontano dalle postazioni: un controllo ogni 1,5 s.
  • Vicino: un controllo ogni 250 ms; marker disegnati solo entro MarkerDistance.
  • Durante il lavaggio il loop gira a ogni frame solo con la lancia in mano, altrimenti ogni 100 ms.
  • Per risparmiare ancora: Config.Markers = false, Config.Gear.hose.enabled = false, Config.Cinematic.enabled = false.

Risoluzione problemi

In mano c'è l'ugello della benzina invece della lancia

Apri F8 e scrivi carwashcheck: indica se il prop non è registrato (file .ytyp) o non si carica (file .ydr). Verifica che stream/ contenga entrambi i file e riavvia la risorsa.

L'idropulitrice non compare o è nel punto sbagliato

Controlla machine = vec4(...) della postazione e rifai le coordinate con /carwashpos. Compare entro Config.MachineSpawnDistance.

“Nessun veicolo fermo sul punto di lavaggio”

Il veicolo deve essere entro il raggio del punto vehicle e con il posto guida libero. Aumenta radius se serve.

Le notifiche non si vedono

Con System = 'esx' serve esx_notify avviato; in alternativa usa 'nui'.

“You lack the required entitlement to use autolavaggio”

La sv_licenseKey del server appartiene a un account Cfx diverso da quello che ha acquistato la risorsa. Usa una license key generata dallo stesso account (portal.cfx.re → Server Management) oppure trasferisci la risorsa all'account giusto.

“Failed to verify protected resource” / la risorsa non si avvia

Un file protetto è stato modificato, rinominato o si è corrotto durante l'upload (es. FTP in modalità testo). Scarica di nuovo la risorsa dal portale Cfx e caricala in modalità binaria, modificando solo i file indicati in File modificabili.
