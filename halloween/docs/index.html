Dolcetto o Scherzetto

Grazie per aver scelto uno script MintDev! Qui trovi tutto per installare, configurare e gestire l'evento di Halloween sul tuo server FiveM.

v1.0.0ESX LegacyQBCoreQboxox_inventoryqb-inventory

01Introduzione

Dolcetto o Scherzetto trasforma il tuo server in un quartiere di Halloween. I giocatori bussano alle porte, raccolgono caramelle e le scambiano alla Bottega delle Caramelle con soldi, cibo a tema, pozioni e oggetti.

Dolcetto

Un residente apre la porta e regala 2–5 caramelle. A volte esce la rarissima Caramella d'Oro.

Scherzetto

5 scherzetti: spavento, allucinazione, maledizione, inseguimento di uno zombie e furto di caramelle.

Bottega delle Caramelle

Interfaccia a tema con cibo, pozioni, oggetti, scambio caramelle → soldi e classifica dei giocatori.

Cibo con effetti

11 cibi e bevande con fame, sete ed effetti speciali, più zucche posizionabili e scatola misteriosa.

04Installazione

  1. Scarica la risorsaDopo l'acquisto la trovi su portal.cfx.re → Assets → Granted Assets. Usa lo stesso account Cfx della sv_licenseKey del tuo server.
  2. Copia la risorsaEstrai lo zip e metti la cartella hw_dolcetto_scherzetto dentro resources/. Non rinominare le sottocartelle.
  3. Avviala dopo framework e inventarioNel server.cfg l'ordine è importante: lo script riconosce il framework all'avvio. 
    ensure es_extended        # oppure qb-core / qbx_core
ensure ox_inventory       # solo se lo usi
ensure hw_dolcetto_scherzetto
  4. Registra gli oggettiScegli il file giusto per il tuo inventario:

    Vale per ESX + ox_inventory, QBCore + ox_inventory e Qbox. Copia il contenuto di install/ox_inventory_items.lua dentro ox_inventory/data/items.lua, all'interno della tabella return { ... }:

    ['hw_caramella'] = {
    label = 'Caramella di Halloween',
    weight = 5,
    stack = true,
    close = true,
    description = 'La moneta di Halloween. Scambiala alla Bottega delle Caramelle!',
},
-- ...e gli altri 15 oggetti del file

    Copia le righe di install/qb-core_items.lua dentro qb-core/shared/items.lua, nella tabella QBShared.Items:

    hw_caramella = { name = 'hw_caramella', label = 'Caramella di Halloween', weight = 5, type = 'item', image = 'hw_caramella.png', unique = false, useable = true, shouldClose = true, description = 'La moneta di Halloween.' },
-- ...e gli altri 15 oggetti del file

    Esegui install/esx_items.sql nel database del server (HeidiSQL, phpMyAdmin...). Le caramelle hanno peso 0, così non riempiono l'inventario.

    INSERT INTO `items` (`name`, `label`, `weight`, `rare`, `can_remove`) VALUES
    ('hw_caramella', 'Caramella di Halloween', 0, 0, 1),
    -- ...
ON DUPLICATE KEY UPDATE `label` = VALUES(`label`), `weight` = VALUES(`weight`);
  5. Copia le immaginiLe 16 icone sono in install/immagini_inventario/:
    • ox_inventory → ox_inventory/web/images/
    • qb-inventory → qb-inventory/html/images/
    • altri inventari → la cartella immagini del tuo inventario
  6. Dai i permessi adminAggiungi l'ace nel server.cfg (dettagli in Permessi): 
    add_ace group.admin hw_dolcetto.admin allow
  7. Riavvia e controlla la consoleAll'avvio deve comparire una riga come questa: 
    [hw_dolcetto] Dolcetto o Scherzetto by MintDev.eu | framework: esx | inventario: ox_inventory
    Se leggi Nessun framework trovato, la risorsa parte prima del framework: sistema l'ordine degli ensure.

05Primo avvio

Lo script è subito utilizzabile, ma le case e la posizione della bottega le decidi tu. In 5 minuti:

  1. Posiziona la BottegaVai dove vuoi il punto di scambio, guarda nella direzione in cui deve guardare il venditore e scrivi /hwnegozio. Di base è a Legion Square.
  2. Crea il quartiereMettiti davanti a una porta, a circa 1,5 metri, guardando la porta, e scrivi /hwcasa aggiungi Via delle Zucche 1. Ripeti per tutte le case dell'evento.
  3. ControllaCon /hwcasa debug vedi tutte le case con il loro ID. Accanto alle porte compare una zucca illuminata.
  4. Avvia l'evento/hwevento on avvisa tutti i giocatori. A fine evento usa /hwevento off.
Consiglio

Raggruppa 15–30 case nella stessa zona (es. Mirror Park o Vinewood Hills): i giocatori si muovono in gruppo e l'evento sembra più vivo.

06Configurazione · Generale

Tutte le impostazioni sono in config.lua, commentate. Dopo una modifica riavvia la risorsa con ensure hw_dolcetto_scherzetto.

Config.Framework = 'auto'   -- 'auto' | 'esx' | 'qb' | 'qbx'
Config.Inventory = 'auto'   -- 'auto' | 'ox' | 'framework'

Config.AdminAce = 'hw_dolcetto.admin'
Config.AdminGroups = { 'admin', 'superadmin', 'god' }

Config.InteractKey = 38         -- E
Config.InteractKeyLabel = 'E'
Config.CancelKey = 73           -- X
Config.SoundVolume = 0.35
Config.Notifications = 'auto'   -- 'auto' | 'esx' | 'qb' | 'qbx' | 'ox' | 'nui' | 'custom'
Config.CustomNotify = function(msg, kind)
    TriggerEvent('chat:addMessage', { args = { 'Dolcetto o Scherzetto', msg } })
end
Config.PreferCustomProps = true

Config.CandyItem = 'hw_caramella'
Config.GoldCandyItem = 'hw_caramella_oro'
Config.GoldScore = 10
OpzioneDescrizione
FrameworkLascia 'auto': riconosce da solo ESX, QBCore o Qbox. Forzalo solo se hai un framework rinominato.
Inventory'auto' usa ox_inventory se è avviato, altrimenti l'inventario del framework.
AdminAce / AdminGroupsChi può usare i comandi admin (vedi Permessi).
InteractKey / CancelKeyTasti per interagire e per annullare un'azione in corso (lista dei controlli).
SoundVolumeVolume degli effetti sonori dell'interfaccia, da 0.0 a 1.0.
NotificationsSistema usato per i messaggi brevi ("Hai comprato...", "Sei troppo lontano", avvisi dell'evento). 'auto' usa quello del framework: ESX.ShowNotification su ESX, QBCore.Functions.Notify su QBCore, le notifiche di qbx_core su Qbox. In alternativa 'ox' (ox_lib), 'nui' (notifiche a tema dello script) o 'custom'. I popup DOLCETTO! / SCHERZETTO!, la barra di avanzamento e la bottega restano sempre a tema.
CustomNotifyLa tua funzione di notifica, usata con Notifications = 'custom' (okokNotify, mythic_notify, ecc.). Gira sul client; kind è 'success', 'error' o 'info'.
PreferCustomPropstrue usa i prop di Halloween inclusi nello script, false i prop originali di GTA.
CandyItem / GoldCandyItemNomi degli oggetti usati come moneta dell'evento.
GoldScoreQuanti punti vale una Caramella d'Oro nella classifica.

07Configurazione · Evento

Config.Event = {
    ActiveOnStart = true,   -- l'evento parte già attivo
    OnlyAtNight = false,    -- true = si bussa solo di notte (ora di gioco)
    NightStart = 19,

Con ActiveOnStart = false l'evento resta spento finché un admin non scrive /hwevento on. Utile per lanciarlo a un orario preciso con un annuncio.

Config.TrickOrTreat = {

    DecorateDoors = true,
    DoorMarker = true,
    ShowBlips = false,

    Chances = { treat = 62, rare = 8, trick = 30 },   -- la somma deve fare 100

        { id = 'allucinazione', weight = 20 },
        { id = 'maledizione',   weight = 20 },
        { id = 'inseguimento',  weight = 18 },

    },

OpzioneDescrizione
RequireBucketSe true serve il Secchiello Zucca. In quel caso metti il suo prezzo a 0 nel catalogo, così tutti possono prenderlo.
HouseCooldownIl cooldown vale per giocatore e per casa: ogni giocatore può ribussare alla stessa porta dopo questo tempo.
KnockSpamPausa minima tra due bussate qualsiasi, contro chi corre da una porta all'altra.
DecorateDoorsZucca illuminata accanto a ogni porta creata con /hwcasa. Si spegne quando hai già bussato.
ChancesProbabilità in percentuale di dolcetto, dolcetto d'oro e scherzetto.
TricksGli scherzetti possibili. weight indica quanto spesso escono; per disattivarne uno toglilo dalla lista.
HallucinationTime, CurseTime, ChaseTimeDurata in secondi di allucinazione, maledizione e inseguimento.
ResidentPeds / MonsterPedsModelli dei personaggi che aprono la porta (dolcetto / scherzetto).
ChaserPed / ThiefPedLo zombie dell'inseguimento e la scimmia ladra.

09Configurazione · Case

Il modo consigliato è crearle in gioco con /hwcasa aggiungi: vengono salvate in data/luoghi.json e funzionano subito, senza riavvio. Puoi anche scriverle nel config:

Config.Houses = {
    { x = -14.87, y = -1441.18, z = 31.19, label = 'Forum Drive' },          -- punto = porta
    { x = 123.45, y = -678.90, z = 30.10, h = 90.0, label = 'La mia casa' },  -- punto = chi bussa (esempio)
}
  • h (heading) è la direzione in cui guarda chi bussa. Con h il punto è "dove sta il giocatore" e accanto alla porta compare la zucca decorativa.
  • Senza h il punto è considerato la porta stessa e la zucca non viene messa.
  • Le case del config hanno ID c1, c2...; quelle create in gioco h1, h2.... Le prime si rimuovono dal config, le seconde con /hwcasa rimuovi.

Catalogo

Ogni voce è un oggetto acquistabile con le caramelle. category decide la scheda: 'cibo', 'bevande' o 'oggetti'.

Catalog = {
    { item = 'hw_burger_mostro',  price = 10, category = 'cibo' },
    { item = 'hw_pozione_strega', price = 12, category = 'bevande' },
    { item = 'hw_zucca_lanterna', price = 15, category = 'oggetti' },
    -- puoi vendere anche oggetti di altri script:
    { item = 'lockpick',          price = 30, category = 'oggetti' },
},
Oggetti esterni

Se vendi un oggetto che non è dello script, aggiungi anche label e description in Config.Items (con type = 'currency' se non deve essere usabile) così la bottega mostra nome e descrizione corretti. Ricorda di mettere la sua immagine in html/img/.

Scambi

Exchanges = {
    { id = 'caramelle_soldi', give = 'hw_caramella',     giveAmount = 1, money = 25 },
    { id = 'oro_soldi',       give = 'hw_caramella_oro', giveAmount = 1, money = 350 },
    { id = 'oro_caramelle',   give = 'hw_caramella_oro', giveAmount = 1, item = 'hw_caramella', itemAmount = 12 },
},

give è l'oggetto che il giocatore consegna. Con money riceve soldi sul conto MoneyAccount, con item + itemAmount riceve un oggetto. Il pulsante "Tutte" scambia tutto in una volta (fino a MaxQuantity).

hunger / thirstQuanto riempie, in percentuale (0–100).
stressValore negativo per togliere stress (QBCore e Qbox).
healPunti vita recuperati.
effect'velocita' super velocità · 'fantasma' giocatore trasparente (lo vedono tutti) · 'ipnosi' effetto visivo · 'vampiro' lampo rosso.

Aggiungere un nuovo cibo

  1. Registra l'oggetto nel tuo inventario (come in Installazione) e aggiungi la sua icona.
  2. Aggiungilo in Config.Items con type = 'food' o 'drink': diventa usabile da solo.
  3. Se vuoi venderlo, aggiungilo a Config.Shop.Catalog e metti l'icona anche in html/img/.

14Come si gioca

Bussare alle porte

Vicino a una casa dell'evento compare una freccia arancione sopra la porta. A meno di 1,6 metri appare il suggerimento [E] Bussa: parte l'animazione e dopo il "toc toc" qualcuno apre. Con X si annulla.

Scherzetti

ScherzettoCosa succede
SpaventoUn mostro (zombie, clown, alieno, Bigfoot...) apre la porta tra il fumo: urlo e il giocatore cade a terra.
AllucinazioneSchermo distorto e tre clown che compaiono intorno al giocatore per 25 secondi.
MaledizioneCamminata da ubriaco e telecamera che ondeggia per 40 secondi.
InseguimentoUno zombie esce e insegue il giocatore. Se lo raggiunge, il giocatore cade.
FurtoUna scimmia ruba 1–3 caramelle e scappa. Senza caramelle diventa uno spavento.

Bottega, cibo e oggetti

  • Alla bottega premi E: scegli la quantità e compra, oppure scambia le caramelle nella scheda Scambio. ESC per chiudere.
  • Cibo e bevande si usano dall'inventario: animazione con il prop in mano, poi fame/sete ed eventuali effetti.
  • Zucca Intagliata: usala per posizionarla davanti a te. Per raccoglierla avvicinati e premi E (solo il proprietario o un admin).
  • Secchiello Zucca: usalo per prenderlo o metterlo via.
  • Scatola Misteriosa: usala per aprirla e scoprire il premio... o lo scherzetto.

ComandoDescrizione

/hwcasa rimuoviRimuove la casa più vicina entro 3 metri.

/hwevento on|offAvvia o ferma l'evento con un avviso a tutti i giocatori.

16Permessi

Un giocatore è admin per lo script se vale almeno una di queste condizioni:

  • ha l'ace hw_dolcetto.admin (o il permesso generale command);
  • su ESX il suo gruppo è in Config.AdminGroups;
  • su QBCore ha uno dei permessi in Config.AdminGroups;
  • su Qbox ha l'ace group.<gruppo> di uno dei gruppi in Config.AdminGroups.
add_ace group.admin hw_dolcetto.admin allow
# oppure per un singolo giocatore:
add_principal identifier.license:xxxxxxxx group.admin

18Testi e traduzioni

Tutti i testi (notifiche, suggerimenti, popup) sono in shared/lang.lua. Per tradurre lo script basta cambiare i valori, lasciando uguali le chiavi e i segnaposto %s / %d:

Lang = {
    prompt_knock    = 'Knock: trick or treat?',
    res_treat_title = 'TREAT!',
    res_treat_text  = 'You got %d candies',
    -- ...
}

I nomi e le descrizioni degli oggetti sono in Config.Items, i testi fissi della bottega in html/index.html e html/script.js.

20Compatibilità e integrazioni

  • Fame e sete: su ESX vengono aggiornate con esx_status; su QBCore/Qbox con i metadata del giocatore e l'evento hud:client:UpdateNeeds, compatibile con gli HUD più diffusi.
  • Oggetti usabili: vengono registrati tramite il framework, quindi funzionano sia con ox_inventory sia con l'inventario del framework.
  • Altri framework o inventari: tutta la parte che parla con framework e inventario è in bridge/server.lua. Adattando quelle funzioni puoi usare lo script anche con sistemi personalizzati.
  • Prestazioni: i cicli si "addormentano" quando non ci sono case o zucche vicine; personaggi e decorazioni vengono creati solo vicino al giocatore.

21Risoluzione problemi

In console compare "Nessun framework trovato"

La risorsa parte prima del framework. Nel server.cfg metti ensure hw_dolcetto_scherzetto dopo es_extended / qb-core / qbx_core e dopo ox_inventory.

Gli oggetti non si possono usare o non compaiono

Controlla di aver registrato tutti i 16 oggetti nel file giusto per il tuo inventario (vedi Installazione) e di aver riavviato l'inventario. Su qb-inventory gli oggetti devono avere useable = true.

Le icone degli oggetti non si vedono

Copia le immagini di install/immagini_inventario/ nella cartella immagini del tuo inventario. Il nome del file deve essere identico al nome dell'oggetto (es. hw_caramella.png).

Vicino alle porte non succede niente

Verifica che l'evento sia attivo (/hwevento on), che OnlyAtNight non sia attivo di giorno e di essere entro 1,6 metri dal punto della casa (/hwcasa debug lo mostra). Se hai già bussato, il suggerimento indica quanto manca al cooldown.

Non trovo la bottega

Ha un blip arancione sulla mappa. Se l'hai spostata con /hwnegozio la posizione è salvata in data/luoghi.json: per tornare a quella del config usa /hwnegozio reset.

Il prop in mano è storto o fluttua

Usa /hwprova nome_oggetto e correggi placement (prop di GTA) o customPlacement (prop personalizzati) in Config.Items o Config.Anims.

In console compare "You lack the required entitlement"

La sv_licenseKey del server appartiene a un account Cfx diverso da quello che ha acquistato lo script. Usa una chiave creata con lo stesso account (portal.cfx.re → Server Management) oppure riscarica la risorsa con l'account giusto.

I prop di Halloween non si vedono

Controlla che la cartella stream/ contenga gli 11 file .ydr e hw_halloween_props.ytyp, che in fxmanifest.lua ci sia la riga data_file e che Config.PreferCustomProps sia true. Dopo aver aggiornato la risorsa svuota la cache del server (cache/) e riavvia.

Il server dice "Sei troppo lontano" anche quando sono vicino

Succede se il punto della casa è stato salvato male (ad esempio da un piano diverso). Rimuovi la casa con /hwcasa rimuovi e ricreala stando davanti alla porta.
