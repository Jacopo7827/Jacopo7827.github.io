Caccia ai Regali

Grazie per aver scelto uno script MintDev! Qui trovi tutto per installare, configurare e gestire l'evento di Natale sul tuo server FiveM.

v1.0.0ESX LegacyQBCoreQboxox_inventoryqb-inventory

01Introduzione

Caccia ai Regali riempie la città di regali nascosti. I giocatori li cercano con un rilevatore "freddo / caldo", li aprono per primi e spendono i fiocchi di neve al Mercatino di Natale, dove c'è anche il calendario dell'Avvento.

Regali nascosti

Regali in punti casuali della mappa: zona sul radar, rilevatore con i campanellini, chi apre per primo vince.

Sorprese

4 sorprese: carbone, scivolone sul ghiaccio, renna impazzita e bufera di neve.

Mercatino di Natale

Dolci, bevande calde, oggetti, scambio fiocchi → soldi, calendario dell'Avvento e classifica.

Extra

Alberi con luci da posizionare, regali da donare ad altri giocatori e calza della Befana.

04Installazione

  1. Scarica la risorsaDopo l'acquisto la trovi su portal.cfx.re → Assets → Granted Assets. Usa lo stesso account Cfx della sv_licenseKey del tuo server.
  2. Copia la risorsaEstrai lo zip e metti la cartella xm_caccia_regali dentro resources/. Non rinominare le sottocartelle.
  3. Avviala dopo framework e inventarioNel server.cfg l'ordine è importante: lo script riconosce il framework all'avvio. 
    ensure es_extended        # oppure qb-core / qbx_core
ensure ox_inventory       # solo se lo usi
ensure xm_caccia_regali
  4. Registra gli oggettiScegli il file giusto per il tuo inventario:

    Vale per ESX + ox_inventory, QBCore + ox_inventory e Qbox. Copia il contenuto di install/ox_inventory_items.lua dentro ox_inventory/data/items.lua, all'interno della tabella return { ... }:

    ['xm_fiocco'] = {
    label = 'Fiocco di Neve',
    weight = 2,
    stack = true,
    close = false,
    description = 'La moneta di Natale. Spendila al Mercatino di Natale!',
},
-- ...e gli altri 13 oggetti del file

    Copia le righe di install/qb-core_items.lua dentro qb-core/shared/items.lua, nella tabella QBShared.Items:

    xm_fiocco = { name = 'xm_fiocco', label = 'Fiocco di Neve', weight = 2, type = 'item', image = 'xm_fiocco.png', unique = false, useable = false, shouldClose = false, description = 'La moneta di Natale.' },
-- ...e gli altri 13 oggetti del file

    Esegui install/esx_items.sql nel database del server (HeidiSQL, phpMyAdmin...). Fiocchi e stelle hanno peso 0, così non riempiono l'inventario.

    INSERT INTO `items` (`name`, `label`, `weight`, `rare`, `can_remove`) VALUES
    ('xm_fiocco', 'Fiocco di Neve', 0, 0, 1),
    -- ...
ON DUPLICATE KEY UPDATE `label` = VALUES(`label`), `weight` = VALUES(`weight`);
  5. Copia le immaginiLe 14 icone sono in install/immagini_inventario/:
    • ox_inventory → ox_inventory/web/images/
    • qb-inventory → qb-inventory/html/images/
    • altri inventari → la cartella immagini del tuo inventario
  6. Dai i permessi adminAggiungi l'ace nel server.cfg (dettagli in Permessi): 
    add_ace group.admin xm_regali.admin allow
  7. Riavvia e controlla la consoleAll'avvio deve comparire una riga come questa: 
    [xm_regali] Caccia ai Regali by MintDev.eu | framework: esx | inventario: ox_inventory
    Se leggi Nessun framework trovato, la risorsa parte prima del framework: sistema l'ordine degli ensure.

05Primo avvio

Lo script è subito utilizzabile, ma i nascondigli dei regali e la posizione del mercatino li decidi tu. In 5 minuti:

  1. Posiziona il MercatinoVai dove vuoi il punto di scambio, guarda nella direzione in cui deve guardare il venditore e scrivi /xmmercatino. Di base è a Legion Square.
  2. Crea i nascondigliVai in un punto all'aperto (dietro una panchina, in un vicolo, su un tetto raggiungibile...) e scrivi /xmregalo aggiungi Nome del posto. Ripeti in giro per la città.
  3. ControllaCon /xmregalo debug vedi tutti i punti: verdi quelli con un regalo nascosto in questo momento. /xmregalo rigenera rimescola i regali.
  4. Avvia l'evento/xmevento on avvisa tutti i giocatori. A fine evento usa /xmevento off.
Consiglio

Metti almeno 3 volte i punti rispetto ai regali attivi (MaxActive): con 8 regali, 25–40 nascondigli rendono la caccia varia e i giocatori non imparano i posti a memoria.

06Configurazione · Generale

Tutte le impostazioni sono in config.lua, commentate. Dopo una modifica riavvia la risorsa con ensure xm_caccia_regali.

Config.Framework = 'auto'   -- 'auto' | 'esx' | 'qb' | 'qbx'
Config.Inventory = 'auto'   -- 'auto' | 'ox' | 'framework'

Config.AdminAce = 'xm_regali.admin'
Config.AdminGroups = { 'admin', 'superadmin', 'god' }

Config.InteractKey = 38         -- E
Config.CancelKey = 73           -- X
Config.SoundVolume = 0.35
Config.Notifications = 'auto'   -- 'auto' | 'esx' | 'qb' | 'qbx' | 'ox' | 'nui' | 'custom'
Config.CustomNotify = function(msg, kind)
    TriggerEvent('chat:addMessage', { args = { 'Caccia ai Regali', msg } })
end
Config.PreferCustomProps = true

Config.FlakeItem = 'xm_fiocco'
Config.StarItem = 'xm_stella'
Config.CoalItem = 'xm_carbone'
Config.StarScore = 10
OpzioneDescrizione
Framework / InventoryLascia 'auto': riconosce da solo framework e ox_inventory.
AdminAce / AdminGroupsChi può usare i comandi admin (vedi Permessi).
InteractKey / CancelKeyTasti per interagire e per annullare un'azione in corso.
SoundVolumeVolume degli effetti sonori (campanellini, regali...), da 0.0 a 1.0.
NotificationsMessaggi brevi: 'auto' usa quelli del framework (ESX.ShowNotification, QBCore.Functions.Notify, qbx_core). Oppure 'ox', 'nui' (a tema) o 'custom'. Popup, rilevatore e mercatino restano sempre a tema.
CustomNotifyLa tua funzione di notifica, usata con Notifications = 'custom' (okokNotify, mythic_notify, ecc.). Gira sul client; kind è 'success', 'error' o 'info'.
PreferCustomPropstrue usa i prop di Natale inclusi nello script, false i prop originali di GTA.
FlakeItem / StarItem / CoalItemNomi degli oggetti usati come monete dell'evento.
StarScoreQuanti punti vale una Stella d'Oro nella classifica.

07Configurazione · Caccia ai regali

Config.Hunt = {
    MaxActive = 8,              -- regali nascosti contemporaneamente
    RespawnTime = 90,           -- secondi prima che ne compaia uno nuovo
    OpenTime = 3500,
    InteractDistance = 1.8,
    PlayerCooldown = 15,        -- secondi tra due regali aperti dallo stesso giocatore

    AreaBlips = true,           -- cerchio sulla mappa (non il punto esatto)
    AreaRadius = 80.0,
    HotCold = true,             -- rilevatore freddo / caldo con i campanellini
    HotColdRange = 120.0,

    Chances = { gift = 62, rare = 8, surprise = 30 },   -- la somma deve fare 100
    Gift = { min = 3, max = 8 },
    Rare = { star = 1, flakes = { min = 5, max = 10 } },

    Surprises = {
        { id = 'carbone',   weight = 30 },
        { id = 'scivolone', weight = 25 },
        { id = 'renna',     weight = 25 },
        { id = 'bufera',    weight = 20 },
    },
    -- ...
}
OpzioneDescrizione
MaxActiveQuanti regali ci sono in giro per la mappa allo stesso tempo. Quando uno viene aperto, dopo RespawnTime ne compare un altro in un punto diverso.
PlayerCooldownPausa minima tra due regali aperti dalla stessa persona, così uno solo non si prende tutto.
AreaBlips / AreaRadiusCerchio sulla mappa nella zona del regalo. Il centro è spostato a caso: il regalo è dentro il cerchio, ma va cercato.
HotCold / HotColdRangeRilevatore a schermo da "Gelido" a "Bollente!" con i campanellini che suonano sempre più veloci. Si attiva entro HotColdRange metri.
GiftLightLuce colorata sul regalo, utile di notte.
ChancesProbabilità in percentuale: fiocchi di neve, Stella d'Oro o sorpresa.
SurprisesLe sorprese possibili e quanto spesso escono; per disattivarne una toglila dalla lista.
BlizzardTime / ReindeerPedDurata della bufera e modello della renna.
PropModello del regalo (personalizzato e originale di GTA).
Chi apre per primo vince

I regali sono condivisi da tutto il server: quando qualcuno inizia ad aprirne uno, gli altri vedono "Qualcuno sta già aprendo questo regalo". Tutto è deciso dal server.

08Configurazione · Punti dei regali

Il modo consigliato è crearli in gioco con /xmregalo aggiungi: vengono salvati in data/luoghi.json e funzionano subito. Puoi anche scriverli nel config:

Config.Spots = {
    { x = 185.5, y = -955.0, z = 30.1, label = 'Legion Square' },
    { x = 501.0, y = 5604.0, z = 797.9, label = 'Vetta del Chiliad' },
}
  • Il punto è dove appare il regalo, a terra. L'altezza viene corretta da sola sul terreno.
  • I punti del config hanno ID c1, c2...; quelli creati in gioco s1, s2.... I primi si rimuovono dal config, i secondi con /xmregalo rimuovi.
  • I punti nel config sono solo d'esempio: crea i tuoi, anche in posti difficili da trovare.

Catalog = {

Scambi

Exchanges = {
    { id = 'fiocchi_soldi',   give = 'xm_fiocco',  giveAmount = 1, money = 20 },
    { id = 'stella_soldi',    give = 'xm_stella',  giveAmount = 1, money = 300 },
    { id = 'stella_fiocchi',  give = 'xm_stella',  giveAmount = 1, item = 'xm_fiocco', itemAmount = 12 },
    { id = 'carbone_fiocchi', give = 'xm_carbone', giveAmount = 5, item = 'xm_fiocco', itemAmount = 1 },
},

give è l'oggetto che il giocatore consegna. Con money riceve soldi sul conto MoneyAccount, con item + itemAmount riceve un oggetto. Il pulsante "Tutti" scambia tutto in una volta (fino a MaxQuantity).

10Configurazione · Calendario dell'Avvento

Il calendario è una scheda del mercatino con 24 porte. Ogni giocatore apre una porta al giorno.

Config.Advent = {
    Enabled = true,
    Mode = 'december',      -- 'december' oppure 'daily'
    Rewards = {
        [1]  = { flakes = 5 },
        [2]  = { item = 'xm_cioccolata', amount = 2 },
        [3]  = { money = 250 },
        [8]  = { stars = 1 },
        [24] = { stars = 3, item = 'xm_albero', amount = 1 },
        -- ...una riga per ogni porta da 1 a 24
    },
}
OpzioneDescrizione
Mode = 'december'Dal 1° al 24 dicembre (data del server) si apre la porta del giorno. Prima del 1° dicembre il calendario è chiuso, dopo il 24 è finito.
Mode = 'daily'In qualsiasi periodo: una porta al giorno in ordine (1, 2, 3...). Utile per eventi fuori dicembre o per i test.
RewardsPremio di ogni porta. Puoi combinare flakes (fiocchi), stars (stelle d'oro), money (soldi) e item + amount (qualsiasi oggetto, anche di altri script).

14Come si gioca

Caccia ai regali

Sulla mappa compaiono cerchi rossi: in ognuno c'è un regalo nascosto. Avvicinandosi parte il rilevatore in alto ("Gelido", "Freddo", "Tiepido", "Caldo", "Bollente!") con i campanellini sempre più veloci. Il regalo gira su sé stesso ed è illuminato. A meno di 2 metri appare [E] Apri il regalo: si scarta in ginocchio per qualche secondo (X annulla).

Sorprese

SorpresaCosa succede
CarboneIl giocatore riceve un pezzo di carbone (5 carboni = 1 fiocco al mercatino).
ScivoloneIl giocatore scivola sul ghiaccio e cade a terra.
Renna impazzitaUna renna arriva al galoppo: se raggiunge il giocatore lo travolge, altrimenti scappa.
BuferaTempesta di neve sullo schermo con la telecamera che trema per 25 secondi.

Mercatino, cibo e oggetti

  • Al mercatino premi E: compra con i fiocchi, scambia nella scheda Scambio, apri la porta del giorno nella scheda Calendario. ESC per chiudere.
  • Dolci e bevande si usano dall'inventario: animazione con il prop in mano, poi fame/sete ed eventuali effetti.
  • Albero di Natale: usalo per posizionarlo davanti a te. Per raccoglierlo avvicinati e premi E (solo il proprietario o un admin).
  • Regalo da Donare: usalo vicino a un amico. Calza della Befana: usala per aprirla.

15Comandi admin

ComandoDescrizione
/xmregalo aggiungi [nome]Aggiunge un nascondiglio nella tua posizione (salvato subito).
/xmregalo rimuoviRimuove il nascondiglio più vicino entro 5 metri.
/xmregalo debugMostra o nasconde tutti i nascondigli (verdi quelli con un regalo attivo).
/xmregalo rigeneraRimescola tutti i regali nascosti.
/xmmercatinoSposta il mercatino nella tua posizione. /xmmercatino reset torna alle coordinate del config.
/xmevento on|offAvvia o ferma la caccia con un avviso a tutti. Spenta, i regali spariscono.
/xmdai [id] [quantità] [stella]Dà fiocchi di neve a un giocatore (aggiungi stella per le stelle d'oro).
/xmreset [id]Azzera calendario dell'Avvento e attese di tutti o di un solo giocatore.
/xmprova [oggetto]Mostra il prop in mano per 10 secondi, per sistemarne la posizione.

/xmevento, /xmdai e /xmreset funzionano anche dalla console del server (senza la /).

16Permessi

Un giocatore è admin per lo script se vale almeno una di queste condizioni:

  • ha l'ace xm_regali.admin (o il permesso generale command);
  • su ESX il suo gruppo è in Config.AdminGroups;
  • su QBCore ha uno dei permessi in Config.AdminGroups;
  • su Qbox ha l'ace group.<gruppo> di uno dei gruppi in Config.AdminGroups.
add_ace group.admin xm_regali.admin allow
# oppure per un singolo giocatore:
add_principal identifier.license:xxxxxxxx group.admin

18Testi e traduzioni

Tutti i testi del gioco (notifiche, suggerimenti, popup, rilevatore) sono in shared/lang.lua. Per tradurre basta cambiare i valori, lasciando uguali le chiavi e i segnaposto %s / %d:

Lang = {
    prompt_open    = 'Open the gift',
    hot_4          = 'Burning hot!',
    res_gift_text  = 'There were %d snowflakes inside',
    -- ...
}

I nomi e le descrizioni degli oggetti sono in Config.Items, i testi fissi del mercatino in html/index.html e html/script.js.

20Compatibilità e integrazioni

  • Fame e sete: su ESX con esx_status; su QBCore/Qbox con i metadata del giocatore e l'evento hud:client:UpdateNeeds, compatibile con gli HUD più diffusi.
  • Oggetti usabili: registrati tramite il framework, funzionano sia con ox_inventory sia con l'inventario del framework.
  • Altri framework o inventari: tutta la parte che parla con framework e inventario è in bridge/server.lua.
  • Insieme a Dolcetto o Scherzetto: i due eventi MintDev usano nomi, comandi e oggetti diversi e possono stare sullo stesso server.
  • Prestazioni: regali, alberi e mercatino vengono creati solo vicino al giocatore; i cicli si fermano quando non c'è niente intorno.

21Risoluzione problemi

In console compare "Nessun framework trovato"

La risorsa parte prima del framework. Nel server.cfg metti ensure xm_caccia_regali dopo es_extended / qb-core / qbx_core e dopo ox_inventory.

Non vedo nessun regalo sulla mappa

Controlla che l'evento sia attivo (/xmevento on) e che ci siano punti (/xmregalo debug). Se tutti i punti sono già occupati non ne compaiono altri: aggiungi nascondigli o abbassa MaxActive.

Il regalo è sotto terra o dentro un muro

Il punto è stato salvato in un posto chiuso o sotto un tetto. Rimuovilo con /xmregalo rimuovi e ricrealo all'aperto.

Gli oggetti non si possono usare o non compaiono

Controlla di aver registrato tutti i 14 oggetti nel file giusto per il tuo inventario e di aver riavviato l'inventario. Su qb-inventory gli oggetti usabili devono avere useable = true.

Il calendario dice "si apre il 1° dicembre"

Con Mode = 'december' conta la data del server. Per usarlo in un altro periodo imposta Mode = 'daily'.

Le icone degli oggetti non si vedono

Copia le immagini di install/immagini_inventario/ nella cartella immagini del tuo inventario. Il nome del file deve essere identico al nome dell'oggetto (es. xm_fiocco.png).

Il prop in mano è storto o fluttua

Usa /xmprova nome_oggetto e correggi placement (prop di GTA) o customPlacement (prop personalizzati) in Config.Items o Config.Anims.

In console compare "You lack the required entitlement"

La sv_licenseKey del server appartiene a un account Cfx diverso da quello che ha acquistato lo script. Usa una chiave creata con lo stesso account (portal.cfx.re → Server Management) oppure riscarica la risorsa con l'account giusto.

I prop di Natale non si vedono

Controlla che la cartella stream/ contenga i 10 file .ydr e xm_natale_props.ytyp, che in fxmanifest.lua ci sia la riga data_file e che Config.PreferCustomProps sia true. Dopo aver aggiornato la risorsa svuota la cache del server (cache/) e riavvia.
